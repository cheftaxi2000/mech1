# Mechanik I Learning Lab

Interactive companion to the ETH Zürich Mechanik I lecture notes: page-referenced lessons, step-by-step derivations, interactive 3D figures, and self-checks — with every formula verified by tests.

**Website:** https://cheftaxi2000.github.io/mech1/ — built and deployed from `main` by `.github/workflows/pages.yml`.

```
npm install
npm run dev     # open the printed URL
npm run check   # typecheck, unit tests, build, browser tests
```

Project memory and rules for contributors (human or Claude): [`CLAUDE.md`](CLAUDE.md). Plan and status: [`docs/`](docs/).
