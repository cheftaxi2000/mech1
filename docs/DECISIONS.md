## D-024 — Visual identity: quiet, Apple-inspired minimalism (2026-10-23) — superseded by D-031
Design-only pass, no content changes. `src/design.css` (loaded after `styles.css`) holds the whole look. Neutral greys (#fbfbfd / #1d1d1f; dark #0b0b0d / #1c1c1e), one blue accent, system sans (SF on Apple devices, Inter elsewhere). Rules: no borders where a fill does the job; boxes are flat filled surfaces with the colour only in their label (lecture/exercise boxes neutral); figures are filled plates without shadow or texture; language switch and explorer tabs are segmented controls; one primary button per figure; sliders slim with a white thumb; source references are plain muted text, not pills; status dots only in the drawer. Home is a calm cover (centred title) followed by plain chapter lists. Spacing scale 4·8·12·16·24·32·48·72, radii 10 (controls) / 14 (surfaces). Physics colours unchanged; 3D scenes stay light in dark mode (D-010 label constraint).

## D-025 — Subject choice as the entry point (2026-10-23)

## D-029 — Short version (Kurz), Mechanik quizzes removed, start at home (2026-10-27)
Student wants a quick-learning version of each course: much less text, formulas and animations stay, text stays where it matters. ## D-031 — Redesign: «annotated lecture book» (2026-10-29, supersedes the look of the earlier design pass)
Student asked for a first-principles redesign (restrained, not AI-template, iPad landscape first-class). Research: educational references (Tufte CSS, Distill and Observable layout sources read directly), font measurements (x-heights, file sizes), codebase audit, independent critique. Decisions:
- **One stylesheet owns the system:** `src/theme.css` (tokens, type, chrome, page grid, blocks, controls, pages), loaded last. `design.css` is gone (its colour roles and index drawings moved to `src/roles.css`); `styles.css` keeps only the physics palette and figure mechanics.
- **Type:** read = serif, operate = sans. Body and headings in **Source Serif 4** (variable, optical sizes), because its proportions match KaTeX's Computer Modern (math at 1.1em meets the text's x-height). UI, labels, page references in **IBM Plex Sans**; code in **IBM Plex Mono**. Fonts are self-hosted from `src/fonts/` (latin subset, ≈ 250 KB, OFL) so every device and the offline artifact look the same. 18 px body (19 px on iPad landscape, 17 px on phones), measure ≈ 39–41 rem.
- **Colour:** warm paper/ink neutrals (`--paper #f7f5f0`, `--ink #1f1d1a`; dark `#151413` / `#e8e4dc`). One UI accent, **olive `--ui #5e6b14`** (dark `#b8c46a`), chosen because every vivid hue is taken by a physics quantity: links (underline), the current place, section numbers, focus, progress. Blue is no longer an interface colour in Mechanik. Physics colours unchanged; `--accent` stays the per-subject *figure* highlight only.
- **Layout:** one left edge for everything read; figures, step animations and explorers extend to the right (`--page 64rem`). From 1360 px a sticky outline of the lesson's sections sits in a left rail; below, the same outline heads the drawer. Section numbers are split off by `<Section>` and hang in the margin on wide screens.
- **Blocks by shape, not tint:** lecture/exercise = solid ink rule (a quotation), supplement = dashed rule (not from the source), intuition = quiet rule, key point = rules above/below, misconception = the only filled block (orange). Figures sit on light plates with a hairline; panels inside a plate are not separate cards.
- **Controls:** flat, 5 px radius, no gradients/blur/shadows; chosen option = ink fill (buttons) or ink underline (segmented choices). Top bar solid with a hairline; on phones language and depth fold behind one «Ansicht» button. Course index is a list with still drawings (no entrance or looping animation). Notes button shrinks to its icon below 1100 px.
