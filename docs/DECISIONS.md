# Decisions

| ID | Date | Decision | Why |
|---|---|---|---|
| D-001 | 2026-10-10 | Vite + React 19 + TypeScript, KaTeX, three.js via @react-three/fiber/drei, Vitest, Playwright. Static site, no backend. | Fast, typed, testable; KaTeX renders synchronously (testable, no flicker); r3f makes 3D figures declarative; static output can be hosted anywhere. |
| D-002 | 2026-10-10 (rev.) | **Both languages, switchable** via a toggle in the sidebar (student's request). Default: stored choice, else English if the browser is English, else German. German: Swiss orthography, «», decimal comma, `;` in tuples. English: German lecture terms kept and glossed. | Student asked for German or English selectable. The notes and exam are German, so the German terms stay visible in English mode too. |
| D-003 | 2026-10-10 | The lecture PDF is **not committed** (`source/*.pdf` is gitignored). `docs/SOURCE_MAP.md` transcribes it page by page instead. | Lecture material may not be redistributable and repo visibility is unknown. **Student to decide**; if the repo is private they may want it committed under `source/`. |
| D-004 | 2026-10-10 | 3D text labels are canvas-texture sprites (`viz/primitives.tsx Label`), not drei `<Html>`. | The first drei `<Html>` per scene rendered empty with React 19 (reproduced in e2e, not StrictMode-related). Sprites are part of the WebGL image and always render. |
| D-005 | 2026-10-10 | Inverse coordinate maps use atan2 / arccos; the lecture's arctan forms are shown and explained (R-001). | Correctness without silently changing the lecture. |
| D-006 | 2026-10-10 | Derivations are expanded by default. | "Explain every meaningful mathematical transition" — collapsing hides steps. Collapsible for revision. |
| D-007 | 2026-10-10 | Every worked example from the notes gets a numeric test in `src/physics/*.test.ts` *before* it is taught. | That is how R-003, R-004, R-007 were found/confirmed. |
| D-008 | 2026-10-10 | The app is published as a private claude.ai artifact: **https://claude.ai/artifact/NKD6xQuLjVjgiubQrXyvy4**. `npm run build:artifact` writes `dist/mech1-lab.html` (no doctype/html/head/body — the host adds them) and `dist/artifact-files.json` (the asset map). Republish by passing that URL as `url`, the html as `file_path` and the asset map as `files`; to drop stale hashed assets, map their old paths to `null`. | The student reads on an iPad; a local dev server is not reachable from there. Hash routes are plain `#topic` because the viewer only passes bare anchors through. |
| D-009 | 2026-10-10 | Derivation animations are SVG figures with absolutely positioned KaTeX labels, driven by a generic `StepPlayer` (steps synced with the numbered derivation text; play/pause, back/next, click a step; autoplay once when scrolled into view; `prefers-reduced-motion` → final frames only). 3D-to-2D transitions use an orthographic camera in `viz/anim/geometry.ts` that moves from the lecture's oblique view to the top view. | Student asked for an animation of the derivation x = ρ cos φ, y = ρ sin φ. SVG + KaTeX keeps labels identical to the formulas in the text (WebGL sprites cannot typeset TeX), is crisp on the iPad and needs no WebGL. Camera interpolation keeps the "drop M into the plane, then look from above" idea continuous. |
| D-010 | 2026-10-10 | No mathematical symbol as plain text anywhere: headings, titles, legends use `<M>`; canvas/SVG labels use the KaTeX_Math font (loaded via `useKatexFontReady`). Enforced by the e2e `plainTextMath` check (Greek letters, √, ², ³, ⊥, ⟂, ∥, ≤, ≥, ≠ outside `.katex`). | Student noticed that φ in a heading (system font) looked different from φ in the formulas (KaTeX `\varphi`). |
