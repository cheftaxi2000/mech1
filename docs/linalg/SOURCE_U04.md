- **7 Rank («Rang»).** Generic echelon matrix with m equations («Anzahl Gleichungen»), n unknowns («n: Anzahl Unbekannte»), pivots ⊛ in r rows, zero rows below with right-hand sides b₁ … b_m. Brace: **r: Rang**. Handwritten: «Will be relevant for all of LinAlg I/II!» and «The number of pivot variables represents the number of lin. independent eqs. as all dependent eqs. will cancel out to be zero!».
- **8 Rank — table** (printed, from a Zusammenfassung): 
  - *Keine Lösung:* r < m und b_i ≠ 0 ∀ i > r (example m = 3, r = 2: rows (1 1 1|1),(0 1 2|1),(0 0 0|1)).
  - *Eindeutige Lösung:* r = n = m (example m = n = 3, r = 3: rows (1 1 1|1),(0 1 1|1),(0 0 1|1)).
  - *Unendlich Lösungen:* r < n und b_i = 0 ∀ i > r; Anzahl freie Parameter: n − r (example n = 3, r = 2: (1 1 1|1),(0 1 2|1),(0 0 0|0); «Free variables = 3 − 2 = 1»).
  - *Ax = b für beliebiges b lösbar:* Voller Rang r = m, oder m = n und Ax = 0 hat nur die triviale Lösung x = 0.
  - *Ax = b für beliebiges b eindeutig lösbar:* Voller Rang r = m und gleich viele Gleichungen wie Unbekannte m = n.

- **9–11 Example from Series 2** (Serie 2, Aufgabe 2): «Geben Sie für a und b Bedingungen an, so dass das System 3x₁ + 2b x₂ + 4x₃ = 5; 3x₁ + 4x₃ = 5; 2b x₂ + 3a x₃ = b (a) Lösungen mit zwei freien Parametern besitzt, (b) mit einem freien Parameter, (c) eindeutig lösbar ist, (d) keine Lösung hat, und geben Sie in jedem Fall die Lösungsmenge an.» Elimination: (3 2b 4|5; 3 0 4|5; 0 2b 3a|b) with −1 → (3 2b 4|5; 0 −2b 0|0; 0 2b 3a|b) with +1 → (3 2b 4|5; 0 −2b 0|0; 0 0 3a|b). 
  (a) two free parameters ⇒ rank must be 1 ⇒ a = b = 0; «Little deviation: both x₂ & x₃ are free, so they need separate variables» L = { ((5−4β)/3, α, β)ᵀ ∈ ℝ³ | α, β ∈ ℝ } (matrix (3 0 4|5; 0 0 0|0; 0 0 0|0)). 
  (b) one free parameter: a ≠ 0, b = 0 (matrix (3 0 4|5; 0 0 0|0; 0 0 3a|0), r = 2). 
  (c) unique: n = m = r, a, b ≠ 0. 
  (d) no solution: a = 0, b ≠ 0 «because last row won't work». (Solution sets for (b), (c), (d) are not written on the slides.)
- **12 Matrix Form of LGS.** 2x₁ + 3x₂ = −1, x₁ − 2x₂ = 3 ⇒ **A·x = b** with A = (2 3; 1 −2) (columns coloured green (2,1)ᵀ and purple/blue (3,−2)ᵀ), b = (−1, 3)ᵀ (red) ⇒ column form (2,1)ᵀ x₁ + (3,−2)ᵀ x₂ = (−1,3)ᵀ. Picture: the two column vectors, the lines «any point along line possible!» through each (multiples x₁·(2,1)ᵀ and x₂·(3,−2)ᵀ), and the combination (2,1)ᵀ(1) + (3,−2)ᵀ(−1) = (−1, 3)ᵀ (so x = (1, −1)ᵀ).
- **13 Linear Dependent Columns (Recap).** (1 −2; 2 −4)(x₁,x₂)ᵀ = (1,4)ᵀ, i.e. (1,2)ᵀ x₁ + (−2,−4)ᵀ x₂ = (1,4)ᵀ. Picture: the columns lie on one line; «Vectors are linearly dependent so solutions can only be on this line»; b = (1,4)ᵀ lies off the line.
- **14 Key Idea.** **Ax = b**: «When considering the Matrix form, we are asking what vector x (e.g. (1,2)ᵀ, (1,−1)ᵀ etc.) lands on the vector b after a transformation by the Matrix A.»

- **21 Where would these vectors land?** (7,19)ᵀ = 7(1,0)ᵀ + 19(0,1)ᵀ, i.e. 𝕀(7,19)ᵀ = (7,19)ᵀ (identity). (2 −3; 1 2)(1,2)ᵀ = (2,1)ᵀ(1) + (−3,2)ᵀ(2) = (−4, 5)ᵀ. (1 −2; 2 −4)(−2,1)ᵀ = (1,2)ᵀ(−2) + (−2,−4)ᵀ(1) = (−4,−8)ᵀ.
- **22 Notation.** A^{m×n}: m rows, n columns; A_{ij} (i row, j column); example A_{(3)(4)}. «Rows before columns» — «Zeilen zuerst, Spalten später».
- **23 Matrix Addition.** (1 2 3; 4 5 6) + (2 2 3; 4 1 2) = (3 4 6; 8 6 8). «Simple index-by-index addition/subtraction. Just make sure the matrices are of the same shape!» A^{m×n} + B^{m×n} = C^{m×n}.
- **24 Matrix Addition, geometrically.** (1 1; 0 2) + (2 0; −1 0) = (3 1; −1 2). Applied to (1,1)ᵀ: (1 1;0 2)(1,1)ᵀ = (2,2)ᵀ; (2 0;−1 0)(1,1)ᵀ = (2,−1)ᵀ; their sum (4,1)ᵀ = (3 1;−1 2)(1,1)ᵀ. Boxed: **(A+B)v = Av + Bv**. «The transformation of a sum of two matrices is the same as applying both transformations separately and adding the result.»
- **25 Scalar** («Skalar»). λ(a b; c d) = (λa λb; λc λd). «Geometrically just stretches space by factor of the scalar.» (5 10 5; 15 5 0) = 5·(1 2 1; 3 1 0).
- **26 Matrix Multiplication.** «Matrix multiplication represents the total transformation after applying two transformations (or "composition"). **backwards** ← AB = C. Applying transformation B and then A is the same as applying transformation C.»
- **27** (0 2; 1 0)(1 −2; 1 0) with colouring: the columns of the right factor are vectors x = (1,1)ᵀ and (−2,0)ᵀ; A·(1,1)ᵀ = (0,1)ᵀ·1 + (2,0)ᵀ·1 = (2,1)ᵀ, A·(−2,0)ᵀ = (0,1)ᵀ(−2) + (2,0)ᵀ·0 = (0,−2)ᵀ; result (2 0; 1 −2). «I'll explain this visually next week» (= visualisation Lesson 05).
- **28 Requirement for Multiplication.** «In case of vector being transformed:» (m×3 matrix)(3×1 vector) = column combination ⇒ «The Matrix must have as many columns as the vector has rows.» «Same applies to Matrix multiplication»: A^{m×n}·B^{n×p} = C^{m×p} — *Required!* the inner n's must agree (marked in red).
- **29 «Finger Computer».** (0 2; 1 0)(1 −2; 1 0): entry (i,j) = row i of the left matrix · column j of the right matrix: 0·1+2·1, 0·(−2)+2·0, 1·1+0·1, 1·(−2)+0·0 ⇒ (2 0; 1 −2).

- **33 Transpose Matrix** («Transponiert»). (A^{m×n})ᵀ → A^{n×m}: columns become rows ((1 2; 3 4; 5 6)ᵀ → (1 3 5; 2 4 6)); (1 2 3; 4 5 6; 7 8 9)ᵀ = (1 4 7; 2 5 8; 3 6 9): «Mirrored across diagonal». Printed ZF excerpt «2.5 Transponierte»: «Die Transponierte einer Matrix erhält man, indem man sie an ihrer Diagonalen „spiegelt“.» Rules: (A+B)ᵀ = Aᵀ+Bᵀ; (A·B)ᵀ = Bᵀ·Aᵀ; (c·A)ᵀ = c·Aᵀ; (Aᵀ)ᵀ = A; (Aᵀ)⁻¹ = (A⁻¹)ᵀ; rang(Aᵀ) = rang(A); det(Aᵀ) = det(A); eig(Aᵀ) = eig(A).

- **35 Symmetric Matrix.** Aᵀ = A, example (1 2 −2 0; 2 2 0 1; −2 0 −3 0; 0 1 0 1). «Note that this has to be a square matrix.» «Comes with lots of useful properties» (printed ZF excerpt 2.9: AᵀA and AAᵀ are always symmetric; eigenvalues real; … Important connections: A symmetric ⇔ A⁻¹ symmetric; A, B symmetric ⇔ A+B symmetric; A symmetric ⇔ A² symmetric; **A, B symmetric, but AB not necessarily symmetric** — highlighted).
- **36 Antisymmetric Matrix** («Anti-/schiefsymmetrische Matrix»). A = −Aᵀ, example (0 1 2 3; −1 0 0 −1; −2 0 0 −2; −3 1 2 0); «Diagonal entries must be zero». Printed ZF excerpt «Schiefsymmetrische Matrix»: −S = Sᵀ; all diagonal entries zero; det(S) = det(Sᵀ) = det(−S) = (−1)ⁿ det(S); eigenvalues imaginary or 0; S can always be written as A − Aᵀ.
